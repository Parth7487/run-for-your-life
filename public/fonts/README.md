# Eleven Eleven Sans Serif Web Fonts (Blanc Salváge)

To use your licensed desktop/web font files for **Eleven Eleven Sans Serif**:
Place your font files in this folder with the following names:
- `ElevenEleven-Bold.woff2` or `ElevenEleven-Bold.otf` / `ElevenEleven-Bold.ttf`
- `ElevenEleven-Regular.woff2` or `ElevenEleven-Regular.otf` / `ElevenEleven-Regular.ttf`

The application stylesheet (`style.css`) automatically detects and binds `@font-face` for `'Eleven Eleven'`, with local system font fallbacks (`local('Eleven Eleven')`) and high-fidelity geometric web twins (`Unbounded` and `Syne`).
