# SCRAM Official Brand Kit & Design System Specification

## 1. Color Palette
- **Brand Primary Red**: `#ec3013` (Dominant action color, play boundary, active pings)
- **Contrast Text Red**: `#ae1800` (Used for small text/eyebrows on light backgrounds)
- **Splash Red**: `#ff3131` (Splash screen branding and high-energy alert rings)
- **Ink (Deep Matte Background)**: `#141312` (Tactical dark theme background)
- **Ink Surface 2**: `#201e1d` (Card background & dialog frames)
- **Ink Surface 3**: `#2e2b29` (Hover card states)
- **Ground (Light mode alternative)**: `#f3f2f2`
- **Hunter Blue**: `#2979ff` (Hunter team indicators and tactical blips)
- **Runner Gold**: `#ffab00` (Runner role indicators and status rings)
- **Border Subtle**: `rgba(255, 255, 255, 0.12)`
- **Border Strong**: `rgba(255, 255, 255, 0.28)`

## 2. Typography
- **Primary Typeface**: `Archivo` (Variable width and weight)
- **Wide Headline Style (.x)**: `font-family: 'Archivo'; font-stretch: 125%; font-weight: 800;`
- **Condensed Counter Style (.c)**: `font-family: 'Archivo'; font-stretch: 62.5%; font-weight: 800;`
- **Monospace Coordinates/Codes**: `JetBrains Mono`, `monospace`
- **System Fallback**: `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", sans-serif`

## 3. Tactile Controls & Dimensions
- **Primary Action Height**: `54px`
- **Border Radius**: `18px` for action cards and buttons, `24px` for game sheets
- **Spring Transition**: `cubic-bezier(.34, 1.56, .64, 1)`

## 4. Brand Vector Assets
- `logo/s.svg`, `logo/c.svg`, `logo/r.svg`, `logo/a.svg`, `logo/m.svg` (Geometric letter slices)
- `icon.svg` (Compass radar crosshair badge)
- `apple-touch-icon.png` (High-res iOS homescreen icon)
- `og-image.png` (Social preview card)
